# Blogs

Blog posts, videos and audio about AWS DevOps Agent, newest first.

- **AWS** posts are from the [AWS Blogs](https://aws.amazon.com/blogs/), which AWS publishes.
- **Community** posts are from all other sites, such as [AWS Builder Center](https://builder.aws.com/), Substack and DEV Community. Anyone with an AWS Builder ID can publish on AWS Builder Center, so its posts are community posts.

!!! warning "Before you follow a post"

    AWS does not endorse community posts. The views in each post are those of its author.

    AWS DevOps Agent changes often. Older posts can describe steps, settings or limits that are no longer correct. For setup and configuration, use the current [AWS DevOps Agent User Guide](https://docs.aws.amazon.com/devopsagent/latest/userguide/).

To suggest a post, add it to [`docs/blogs/posts.json`](https://github.com/aws/tools-for-devops-agent/blob/main/docs/blogs/posts.json) in a pull request. Use tags from [`docs/blogs/tags.json`](https://github.com/aws/tools-for-devops-agent/blob/main/docs/blogs/tags.json).
