# Connectors Catalog

Browse connectors: MCP servers that a partner hosts, which you add to AWS DevOps Agent without deploying anything to your AWS account. Each connector page explains what to set up in the partner's product before you connect it, and which skills come with it.

## How Connectors Work

A connector is the definition of a partner-hosted MCP server: its endpoints, how you authenticate to it, and the skills that help the agent use it. A connector holds no code. You add it from the AWS DevOps Agent console, sign in or enter credentials for the partner's product, and the agent can use the server's tools during investigations.

Connectors marked **Coming Soon** are defined in this repository but aren't in the console yet. A newly released connector can take a few days to reach the console in every AWS Region.

For MCP servers you deploy in your own AWS account instead, see the [MCP Servers catalog](../mcp-servers/index.md).
