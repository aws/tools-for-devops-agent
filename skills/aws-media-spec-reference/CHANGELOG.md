# Changelog

## 1.0.0 (2026-10-27)

- Initial contribution to aws/tools-for-devops-agent: Media Spec Reference (AV1, SCTE-35, SCTE-104, MediaPackage v2 response headers).
- Lookup tables for AV1 profiles, tiers and levels, SCTE-35 splice commands with the full segmentation_type_id and UPID tables, SCTE-104 opIDs, request types and result codes, and MediaPackage v2 manifest and segment response headers including CMSD fields.
- Knowledge-only; no AWS API permissions required.
- Shaped to the DevOps Agent skill-eval best practices: the description opens with when to use the skill, reference links carry load conditions, and a Gotchas section and a self-check before answering were added.
