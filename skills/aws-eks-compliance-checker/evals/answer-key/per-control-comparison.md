# Per-control comparison with the answer key

`key-<cluster>.json` holds the answer key. Under `AmazonAIOpsAssistantPolicy` a control matches when its status is one the key allows (for example `Not assessed`, or `FAIL` where the reads that succeed prove it).

Each run is compared using its delivered report: the last `final_response` in the journal. The harness judge grades the first one, which in runs that delegate to background tasks is often an interim message, so the harness's without-skill scores understate those runs. The baseline's own status words are mapped to the skill's (`NOT-VERIFIABLE` and `N/A` to Not assessed, `advisory` to Manual review), and for the host-only Section 3 controls Not assessed counts the same as Not covered. Control IDs are compared as numbered in CIS v1.8.0; a report that numbers them differently mismatches on those rows.
