# Changelog

## 1.0.0
- Initial version
- System prompt that routes GenAI and LLMOps questions to fourteen `llmops-*` skills: incident triage, quality evaluation, Bedrock configuration, permissions audit, guardrails, capacity and cost, knowledge bases, agent runtime, and six SageMaker skills
- Three modes: incident triage (leads with a `TRIAGE:` line), on-demand investigation, and a scheduled proactive posture assessment
- Read-only; uses the `use_aws` tool
